Class: Level

Level(enemies, clouds, backgroundObjects, coins, bottles)

new Level(enemies, clouds, backgroundObjects, coins, bottles)

Creates a new Level instance containing all game entities such as enemies, clouds, background objects, coins, and bottles.
Parameters:
Name Type Description
enemies Array Array of enemy objects in the level.
clouds Array Array of cloud objects in the level.
backgroundObjects Array Array of background objects used for scenery.
coins Array Array of collectible coin objects.
bottles Array Array of collectible or usable bottle objects.
